🎨 PayroTech Design System v1.0

A comprehensive design system with CSS variables, animations, typography, and reusable components for consistent UI/UX across the entire PayroTech platform.

📦 Installation

The design system is automatically loaded via the layouts. To use it in custom pages:

<!-- In your HTML head -->
<link href="~/css/design-system.css" rel="stylesheet">

<!-- Before closing body tag -->
<script src="~/js/design-system.js"></script>

🎨 CSS Variables (Design Tokens)

Use these variables for consistent theming:

/* Colors */
var(--pt-primary-500)    /* Primary blue */
var(--pt-success-500)    /* Success green */
var(--pt-warning-500)    /* Warning amber */
var(--pt-danger-500)     /* Danger red */

/* Semantic Colors (auto-switch in dark mode) */
var(--pt-bg-primary)     /* Main background */
var(--pt-bg-card)        /* Card background */
var(--pt-text-primary)   /* Primary text */
var(--pt-text-secondary) /* Secondary text */
var(--pt-border-primary) /* Border color */

/* Spacing */
var(--pt-space-2)  /* 0.5rem */
var(--pt-space-4)  /* 1rem */
var(--pt-space-6)  /* 1.5rem */
var(--pt-space-8)  /* 2rem */

/* Border Radius */
var(--pt-radius-md)   /* 8px */
var(--pt-radius-lg)   /* 12px */
var(--pt-radius-xl)   /* 16px */
var(--pt-radius-full) /* Fully rounded */

/* Shadows */
var(--pt-shadow-sm)  /* Subtle shadow */
var(--pt-shadow-md)  /* Medium shadow */
var(--pt-shadow-lg)  /* Large shadow */

⌨️ Keyboard Shortcuts

<script>
// Default shortcuts (auto-registered):
// Ctrl+K - Command palette
// N - New employee
// E - Employees list
// D - Toggle dark mode
// ? - Show shortcuts help

// Register custom shortcut
PT.Shortcuts.register('s', () => {
    document.getElementById('searchInput').focus();
});

// Unregister
PT.Shortcuts.unregister('s');
</script>
